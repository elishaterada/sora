# Working Name: Sora

Sora is currently a project codename, not a cleared public product name.

## Strengths

- short and easy to pronounce
- starts with `S`, making it convenient to launch through Spotlight
- `sora` means “sky” in Japanese
- supports a light, open, forward-looking visual identity

## Known concerns

- strong existing association with OpenAI's Sora product
- existing AI, workflow, editor, and developer-tool uses
- poor ownership of exact search results and primary domains
- likely trademark and commercial-friction risk in software and AI categories

## Rule for agents

Use Sora in project files only as the working name. Do not:

- claim the name is available or legally cleared
- purchase domains
- create public accounts
- publish a product page
- spend implementation time on branded assets

Before public launch, run a fresh commercial screen, live domain check, entity-name check, and attorney-level trademark review in the intended markets.
